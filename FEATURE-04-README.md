# PaperStack Feature #4 — Contributor Profile + XP + Impact

This feature upgrades the existing leaderboard into a contribution reputation system.

## Added

- Public contributor profiles
- Personal `/contributors/me` impact profile
- Contribution XP
- Campus contributor rank
- Approved paper count
- Solution contribution count
- Fulfilled missing-paper/request count
- Views/downloads generated by contributed papers
- Impact badges
- Recent approved contribution history
- Private pending / correction / rejected counts for the signed-in contributor

## XP rules

- Approved question paper: **+100 XP**
- Solution included: **+150 XP**
- Requested/missing paper fulfilled: **+200 XP**

XP is calculated dynamically from existing PaperStack data. No XP migration or persistent counter is needed.

## Privacy improvement

The new public leaderboard/profile API does **not** expose contributor email addresses.

## Install

From `D:\PaperStack`:

```powershell
node .\apply-feature-04.js
node .\verify-feature-04.js
cd server
npm test
cd ..\client
npm run build
```

Then restart backend/frontend.

## Test URLs

- `http://localhost:3000/contributors`
- `http://localhost:3000/contributors/me` (logged in)
- Open any contributor from the leaderboard.

Backend:

- `http://localhost:5000/api/contributors/leaderboard`
- `http://localhost:5000/api/contributors/rules`

## No migration

Feature #4 does not modify MongoDB schema or require a data backfill.
